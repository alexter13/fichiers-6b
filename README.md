# Fichiers 6b

Explorateur de fichiers Android **sans publicité, sans pistage, sans compte**, édité par [6bernova](https://www.6bernova.fun).

## 📥 Installer

### 👉 [Télécharger Fichiers 6b](https://github.com/alexter13/fichiers-6b/raw/main/Fichiers6b.apk)

*(lien direct, toujours la dernière version - actuellement **1.3**)*

1. Sur le téléphone, touchez le lien ci-dessus : le fichier `Fichiers6b.apk` se télécharge.
2. Ouvrez le fichier téléchargé. Si Android le demande, autorisez votre navigateur à **installer des applications inconnues**, puis touchez **Installer**.
3. Au premier lancement, touchez **Accorder l'accès** puis activez **Accès à tous les fichiers**.

Les mises à jour arrivent ensuite **directement dans l'application** : un message « Mise à jour disponible » s'affiche, touchez **Installer**. Réglages, connexions et favoris sont conservés.

> Android 8.0 ou plus récent. Google Play Protect peut afficher un avertissement car l'application ne vient pas du Play Store : touchez **Plus de détails → Installer quand même**.

## ✨ Fonctions

- Stockage interne, carte SD, clé USB, onglets, double volet, grille ou liste, miniatures
- Copier / déplacer / renommer (aussi en lot), corbeille restaurable
- Archives ZIP : parcourir, extraire, créer (chiffrement AES-256)
- Éditeur de texte, visionneuse d'images, empreintes MD5 / SHA-256
- Réseau : **Google Drive**, SMB (Windows / NAS), SFTP, FTP / FTPS
- Recherche récursive, gros fichiers, doublons, applications installées

## ☁️ Google Drive

La connexion à Google Drive est réservée aux comptes autorisés par l'éditeur (application en phase de test chez Google). Demandez l'ajout de votre adresse Gmail à 6bernova. À la première connexion, Google affiche « Application non validée » : touchez **Continuer**.

## 🔒 Confidentialité

Aucune donnée ne quitte votre téléphone, sauf vers les serveurs que **vous** configurez (Drive, NAS, SFTP…). Pas de publicité, pas de statistiques, pas de traqueur. Les mots de passe sont chiffrés par le Keystore Android.
